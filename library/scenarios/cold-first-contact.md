# Cold first contact

## Purpose

A first email to someone who has never heard of the sender. Tests whether the agent finds a real hook in thin information without inventing a relationship.

## Must include

- A hook taken from the input (here: the post about shortages).

## Avoid

- Pretending to have met or spoken before ("as discussed", "great to reconnect").
- Details about the lead that the input does not give.

## Examples

## Done when

- [must] Does not imply any previous contact.
- Uses the information from the input as the reason for writing.
